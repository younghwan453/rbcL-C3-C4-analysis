일반 샌드박스에서 PowerShell 시작 단계의 `setup refresh had errors`는 재현됐습니다. 권한 승인된 PowerShell 실행으로 Git, 파일 읽기·쓰기, Conda와 두 네트워크 엔드포인트를 확인했습니다. 네트워크 응답은 두 곳 모두 HTTP 200이었습니다.

노트북 실행 중 Windows ZMQ 보조 이벤트 루프와 커널 TCP 전송에 대한 경고가 표시됐습니다. 세 코드 셀은 정상 완료되어 출력이 노트북에 저장됐습니다.
