# 13주차 AI 협업 기록

1. **해결하려던 문제**. 같은 30종에서 rbcL 코돈 사용, RbcL 아미노산 조성, 서열 기반 특성을 계산하고 광합성 유형과 분류군에 따라 비교합니다.
2. **AI에 제공한 입력과 문맥**. 12주차 커밋 `04714c1`의 검증된 CDS·단백질 FASTA, 검증표, 종 메타데이터와 11주차 연구 계획을 불러왔습니다.
3. **AI가 제안한 내용**. 두 FASTA의 종 ID를 맞추고 CDS 번역을 재검증한 뒤, 종별 CSV와 그룹 요약표를 만들었습니다. 히트맵에서 동의 코돈을 모아 배치했습니다.
4. **채택한 내용과 이유**. 종마다 동일한 가중치를 주고 C3·C4 전체와 분류군별 값을 함께 보여 주었습니다. 특정 동의 코돈군의 관측 수가 0일 때 RSCU를 빈칸으로 유지하는 규칙을 적용했습니다. 학생의 개별 구현 검토 여부는 미확인입니다.
5. **거절한 내용과 이유**. 학생이 직접 거절한 항목은 미확인입니다.
6. **학생이 직접 수정한 부분**. 코드 및 문서의 학생 직접 수정은 미확인입니다.
7. **수행한 테스트**. 손 계산, 대체 시작 코돈, 오류 입력, RSCU 결측 처리, 종 ID 연결과 실제 자료 산출물을 검사했습니다. [테스트 기록](test_results.md)
8. **발견한 오류 및 알려진 한계**. Windows에서 Conda 경로를 설정하지 않고 Python을 직접 실행했을 때 그림 출력에서 DLL 오류가 발생했습니다. 기존 환경의 라이브러리 경로를 적용해 해결했습니다. 원본 프로젝트의 쓰기 권한 제약으로 커밋의 작업 사본에서 실행했습니다. 조성 차이는 단일 유전자와 서로 관련된 종들에서 관측한 기술통계입니다.
