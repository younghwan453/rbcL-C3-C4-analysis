# 13주차 테스트 결과

독립 Conda 환경 `rbcL`에서 전체 테스트 **25건 통과, 0건 실패**를 확인했습니다. 11·12주차 회귀 테스트 19건과 13주차 테스트 6건을 실행했습니다. 이번 주에 계획한 자동 테스트는 모두 실행했습니다.

| 13주차 테스트 | 상태 | 확인한 내용 |
| --- | --- | --- |
| 손 계산 및 결측 | 통과 | 알라닌 개수·비율, GRAVY, aromaticity, 코돈 빈도·RSCU, 사용되지 않은 코돈과 미관측 코돈군 |
| 대체 시작 코돈 | 통과 | GTG 시작을 단백질에서는 M, DNA 코돈 사용에서는 GTG로 처리 |
| 오류 입력 | 통과 | 모호 염기, 비표준 아미노산, 번역 불일치, 내부 stop, 종결 코돈 누락, 프레임 오류 |
| 그룹 요약 | 통과 | 종 단위 동등 가중치, RSCU 결측 제외, 유효 n과 표본 표준편차 |
| 입력 연결 | 통과 | 종 ID 불일치 검출 |
| 실제 자료 및 출력 | 통과 | 30종 자료 일치, 20개 표준 아미노산과 61개 의미 코돈, 개수·백분율 합계, 동의 코돈군 RSCU 합계, 종별·그룹별 집계, PNG 5개의 파일 무결성과 300 dpi |

## 손 계산 예

`ATG GCT GCT GCC TAA`를 번역하면 `MAAA`입니다. 종결 코돈을 빼면 분모는 4개입니다.

- 알라닌 3개, 75%. GCT 2개, 50%.
- 알라닌의 동의 코돈은 4개이므로 코돈당 기대 횟수는 3/4입니다. GCT의 RSCU는 2/(3/4) = 8/3이고, GCC는 1/(3/4) = 4/3입니다. GCA는 관측 수 0으로 RSCU가 0입니다.
- 트립토판이 없으므로 TGG의 RSCU는 결측입니다.

## 독립 재실행

기존 결과가 없는 별도 임시 폴더에 12주차 입력 파일 4개와 분석에 필요한 스크립트 2개를 복사했습니다. `python -m scripts.week13_composition`을 다시 실행해 CSV 5개와 300 dpi PNG 5개가 원래 작업 사본의 산출물과 바이트 단위로 모두 일치함을 확인했습니다. 전체 테스트 명령은 `python -m unittest discover -s tests`입니다.
