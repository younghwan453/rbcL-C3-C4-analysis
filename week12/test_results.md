# 12주차 테스트 결과

`conda run -n rbcL python -m unittest discover -s tests`로 실행했습니다. 최종 자동 테스트는 11주차 회귀 테스트 7건과 12주차 테스트 12건을 합해 19건 통과했습니다.

| 검증 항목 | 결과 |
| --- | --- |
| 역방향 CDS, 주석 번역표 우선 적용 및 기본 표 11 | 통과 |
| 불완전 좌표, 모호염기, 3의 배수가 아닌 길이 거부 | 통과 |
| 내부 stop, 잘못된 종결 또는 주석 번역 불일치 거부 | 통과 |
| 종명 대조 및 구형 독립 CDS의 제목·산물 교차 검증 | 통과 |
| RefSeq 우선 선택, 중복 accession 제외와 원본 보존 | 통과 |
| 12 nt 손 계산 예제와 최소 의미 코돈 경계 | 통과 |
| FASTA 연결 오류, 그룹 집계 및 네 PNG의 300 dpi | 통과 |
| NCBI 시험 수집과 확대 수집 | 4/4 및 30/30 통과 |
| GenBank 원본, 두 FASTA, 종별 CSV 및 표준편차 독립 대조 | 30종 통과 |
| 빈 임시 디렉터리에서 보관된 데이터로 GC 분석 재실행 | CSV 2개와 PNG 4개가 기존 파일과 바이트 단위로 일치 |
| 전체 프로젝트의 최종 재현 실행 | 미실행 · 15주차 예정 |

첫 통합 테스트에서는 Pandas가 변환 결과에 기존 열과 같은 이름을 허용하지 않아 코돈 위치 그림의 열 이름을 바꿨습니다. 이후 후보 교체에서 드러난 11주차 테스트의 종 이름 고정을 실험 설계 조건인 Flaveria C3·C4 각각 2종 검사로 바꾸고, 시험 수집 종은 별도 테스트로 유지했습니다. Seaborn의 Matplotlib `vert` 인자 사용으로 버전 호환성 경고가 표시됐으며 현재 환경에서 그림 저장은 완료됐습니다.
